---
name: Dashboard removal
description: Intentional removal of the public role-switching dashboard preview.
---

Do not restore the preview dashboard, role-switching UI, navigation link, or post-form links to it unless the user asks for a dashboard again.

**Why:** The user explicitly asked to remove the preview dashboard page. The request form remains a local-only preview and must not imply that its confirmation creates a dashboard record.

**How to apply:** When editing navigation, request confirmations, or user-facing preview copy, keep the dashboard absent and describe form results only as local previews.
