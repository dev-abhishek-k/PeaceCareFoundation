# Project notes

NGO Help Network is a frontend-only UI prototype. The previous Peace Care Foundation site has been replaced in the running workflow. Do not treat demo data or local state as real requests, verified NGOs, accounts, payments, or persistent records.

Run with `bun run dev` (Vite port 5000); check with `bun run typecheck` and `bun run build`. No backend or database is needed, and the imported Supabase settings are unused.
