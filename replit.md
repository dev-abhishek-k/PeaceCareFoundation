# Project notes

Peace Care Foundation is a frontend-only UI prototype. Keep its name and mission content focused on care for homeless dogs, children, adults and elders, while retaining the sample NGO-directory and support journeys. Do not treat demo data, past impact figures, verification badges, local state or sample contact details as real requests, verified NGOs, accounts, payments or persistent records. Do not add live donation or payment flows.

Run with `bun run dev` (Vite port 5000); check with `bun run typecheck` and `bun run build`. No backend or database is needed, and the imported Supabase settings are unused.
